# E2E-тесты

Тесты используют уже работающий API gateway. Нужны существующий покупатель
с достаточным балансом и UUID товара в наличии. Каждый успешный запуск
`TestCheckout` оформляет один заказ.

Перед запуском укажите `E2E_EMAIL`, `E2E_PASSWORD` и `E2E_PRODUCT_ID`
в корневом `.env` или экспортируйте их в терминале. Запустите из корня
репозитория.

```sh
make e2e
```

Цель запускает одноразовый Compose-контейнер. По умолчанию он обращается
к `http://gateway` во внутренней сети Docker. Для другого адреса задайте
`E2E_BASE_URL`.

Для запуска только авторизации используйте:

```sh
docker compose run --build --rm --no-deps -T e2e -run TestAuth
```
